# GameJam-DVJ-2025-G13
>Hello, World!

>Hello World! es un juego sobre un robot, W-4-VE, que intenta camuflarse entre una gran variedad de carismáticos personajes de la universidad Robotnik. Con la meta de llegar a saludar al rector antes de que se marche, W-4-VE tendra que elevar su popularidad entre los alumnos y profesores para llegar a saludar al famoso rector.
